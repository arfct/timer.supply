Timer Supply is a countdown timer with one input field. The user opens the page, types a duration and presses enter. There is no settings panel and no account. The digits fill the screen and pulse while they count down, and a row of faint presets sits below them. It was built in 2019 for presentations, pomodoros and pasta.

The whole page is a single HTML file set in Courier. There is nothing to install or configure.

HTML, CSS and JavaScript. 2019.
